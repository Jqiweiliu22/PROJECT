# Collection Explorer

面向课程学习者的公开馆藏浏览样本。界面以英语为主，配合少量有来源的 Noongar 标签，结合澳大利亚国家博物馆（NMA）馆藏目录与西澳州立图书馆（SLWA）历史照片开放数据，帮助用户检索物件与图像、核对出处、比较类别与年代。本运行说明使用中文。

**这是可在本机运行的学习样本。尚未公开部署，也不等于已经完成课程项目。** 当前组合目录含 712 条记录：407 条 NMA 物件与档案记录，以及从 SLWA Digital Photographic Collection 筛选的 305 条历史照片记录；图片展廊共显示 316 条带来源图片的记录。

## 在 VS Code 中运行

1. 安装 **Python 3.9 或以上**。本项目仅使用 Python 标准库，无需安装第三方依赖。
2. 解压项目，在 VS Code 中选择“文件 → 打开文件夹”，打开包含 `app.py` 的 `Collection_Explorer` 文件夹。
3. 打开“终端 → 新建终端”，确认终端位于该文件夹，运行：

   macOS / Linux：

   ```bash
   python3 app.py
   ```

   Windows：

   ```powershell
   py app.py
   ```

4. 浏览器通常会自动打开。也可手动访问 [http://127.0.0.1:8000/](http://127.0.0.1:8000/)。保持终端开启；按 `Ctrl+C` 停止服务。

若 8000 端口已被占用，运行 `python3 app.py --port 8001`，Windows 用 `py app.py --port 8001`，再访问 [http://127.0.0.1:8001/](http://127.0.0.1:8001/)。添加 `--no-browser` 可关闭自动打开浏览器。

**必须通过 `app.py` 启动。** 双击 `index.html`、使用 `file://` 或仅启动静态网页预览，不能提供本项目所需的 Python 搜索 API。若修改 Python 文件或 JSON 数据，请停止并重启服务；修改页面样式后刷新浏览器。

## 使用方式

- **馆藏探索（Explore）**：默认图片展廊（Image gallery），展示 316 条有对应来源图片的记录；完整目录（Full catalogue）切换为 712 条记录的表格，每页 12 条。没有图片的记录仍可阅读，不以其他图片代替。
- **搜索与筛选**：目录保留英文，请尝试 `brass`、`poster`、`Tuckerbox` 等词。可结合类别、材料、地点及关系、制作年份筛选，或按相关度、标题、年代排序。完整目录更适合范围检索；图片展廊无匹配时，可切换完整目录。
- **藏品详情**：点击标题或卡片，查看馆藏编号、制作日期、材料、尺寸、地点关系、来源与许可。页面保留馆方提供的简介、实物描述、意义说明、教育说明、相关日期和链接；未提供的字段不会补写。有图记录可放大查看，并可跳转馆方原始记录。
- **馆藏统计（Insights）**：统计当前浏览方式和筛选条件下的全部匹配记录，而非当前页。显示总数、已知／未知年份、前 10 类分布和十年区间分布。查看全部 712 条的统计前，请切换完整目录并重置条件。
- **来源与语言（Sources & language）**：说明快照来源、原始目录用语、数据局限、Noongar 标签出处及使用条件。重置按钮清除搜索条件，但保留当前浏览方式。

外部图片加载失败时，页面会显示提示，目录检索仍可使用。修改模式和筛选条件不会修改数据文件。

## 搜索算法与统计口径

`collection_core.py` 实现主要计算：将查询做 Unicode `casefold`，按词切分并去重；逐条记录、逐词检查字段。**每个词都必须在至少一个字段中出现**，不同词可以匹配不同字段。每词的字段匹配权重如下，同一字段对同一词最多计分一次：

| 字段 | 标题 | 类别 | 材料 | 地点及关系 | 所属收藏 | 日期原文 | 来源机构 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 权重 | 8 | 4 | 3 | 2 | 1 | 1 | 1 |

一个词若匹配多个字段，累加相应权重；总分高者优先，同分按记录 ID 排序。这是字段子串匹配，不是语义搜索或中文翻译搜索。类别、材料和地点筛选使用完整标签的精确匹配。

图片模式先排除空图片链接，再应用其他筛选、排名、统计和分页。年份范围为包含端点的区间；记录的制作日期区间与检索区间重叠即可匹配，未知年份会被年份筛选排除。年代排序始终把未知年份放在最后；十年图按制作起始年份计数，每件计一次。界面类别采用所选馆方第一类别，不把一件藏品重复计入多个类别。

搜索上限 160 字符；年份须为 1–2100 的整数，起始年不能晚于结束年。页码从 1 开始，超出结果末页时自动回到末页；没有结果时显示空状态。筛选下拉选项来自完整目录，因此有些选项在当前图片模式下可能没有结果。

## 数据、图片与限制

本地快照组合两套公开来源：NMA Collection API 的 `Aboriginal` 检索保留 407 条记录；[SLWA Digital Photographic Collection](https://catalogue.data.wa.gov.au/en/dataset/digital-photographic-collection) 的 19,166 条书目行中，以 Aboriginal、Noongar、Nyungar 和 Indigenous 关键词初筛，并排除选定的仪式、限制、拘禁、丧葬、人体遗骸、性暴力及裸露词语，保留 305 条有标题和图片链接的历史照片记录。该自动筛选不等于社区或文化审核。

NMA 目录文字按 [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/) 使用，图片按逐件许可；SLWA 开放数据按 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) 使用。网站显示原始远程图片地址，不把图片复制进项目。每条详情显示来源机构、许可、原图和相关链接。

标题、说明和图注保留来源英文；未用 AI 生成文化故事、翻译目录或推断 Country。历史记录可能含逝者姓名、人物图像以及过时或冒犯性用语。关键词关联不等于原住民创作、文化权威或特定 Country 联系。正式使用前应逐条复核并咨询课程负责人或相关社区机构。

Sources & language 页面另列 AIATSIS、Noongar 社区与语言机构、SLWA、Trove、Collections WA、BOM、ABS、Data WA 等 12 个研究入口。它们用于继续查证，不是本地数据快照的一部分，各自有独立的访问和再使用条件。

程序启动时只读取 `data/collections.json`，不实时调用外部 API。断网时目录搜索、详情文字和统计仍可工作；远程图片和外部链接需要网络。
## 测试

在项目文件夹运行：

```bash
python3 -m unittest discover -s tests -v
```

Windows 对应命令：`py -m unittest discover -s tests -v`。截至 2026-10-05，**38 项自动测试通过**，覆盖加权排名、AND 匹配、Unicode、组合筛选、空结果、未知年份、区间边界、图片模式、详细字段校验、分页统计、重复 ID、非法输入、API 响应和静态文件保护。测试使用合成数据及内存 HTTP 请求，不访问外网。

学生仍需在自己的环境手动复测：打开图片与详情、切换完整目录、组合搜索、观察统计变化、翻页、输入无结果关键词，以及输入“起始年晚于结束年”的失败情况。记录操作步骤、实际结果和修复情况。

## 文件与扩展位置

| 文件 | 用途 |
| --- | --- |
| `app.py` | 本地 HTTP 服务、API 路由、静态文件白名单 |
| `collection_core.py` | 数据验证、加权检索、筛选、统计与分页 |
| `index.html` / `styles.css` / `script.js` | 页面结构、外观、交互与图表 |
| `data/collections.json` | 带来源与许可的本地数据快照 |
| `tests/test_core.py` | 38 项自动测试 |
| `docs/architecture.svg` / `docs/architecture.md` | 架构图和数据流说明 |
| `docs/language-sources.md` | 选定 Noongar 标签的社群来源与使用说明 |
| `AI-LOG.md` | 本次 AI 使用记录及学生续写模板 |

改变视觉样式可编辑 `styles.css`；修改算法应同时更新测试、统计说明和 AI 日志。替换数据时需保持字段结构、唯一 ID、许可与原始来源。默认服务器仅绑定 `127.0.0.1`；它不采集访客账户或表单个人资料，也没有写入数据的 API。服务限制可访问的静态文件，并验证搜索输入。
